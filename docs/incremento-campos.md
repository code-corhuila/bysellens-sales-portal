# Campos de la venta
Extrae las secciones originales de cliente, productos y método de pago de Ventas.tsx.
Conserva opciones, filtrado, subtotales, límites y acciones; los callbacks reciben
los valores para que la lógica de la página gestione el estado.
Se asocian las etiquetas a sus campos para accesibilidad y pruebas.
CamposVenta.css preserva reglas de secciones, selects, líneas y responsive original.
No se conecta la ruta ni se implementan servicios adicionales en este incremento.
