# Historial de Ventas
Extrae la tarjeta, tabla, búsqueda, actualización y estados originales de Ventas.tsx.
HistorialVentas.css conserva las declaraciones y media queries de esas secciones.
Se mantiene la búsqueda original y el contador sobre todas las ventas, así como
el estado vacío solo cuando no hay registros (no cuando un filtro no coincide).
El componente recibe datos y acciones; no importa servicios internos de otros portales.
La ruta permanece temporal hasta integrar todos los componentes revisados.
